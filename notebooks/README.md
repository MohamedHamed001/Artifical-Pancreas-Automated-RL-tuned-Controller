# Notebooks

Use this folder for exploratory analysis, training curves, and paper figures.

Suggested workflow:

1. `python -m venv .venv && source .venv/bin/activate`
2. `pip install -e ".[demo,dev]"` (Python **3.9–3.12**; see root `README.md`)
3. Create notebooks here; keep outputs cleared before committing unless small.

The upstream LunarLander PID-tuning tutorial notebook lives under
`docs/legacy-pid-tuner/` for historical reference.
